# Glide

[English](README.md) | 简体中文 · **[官网](https://calabli.github.io/glide/)** · [下载](https://github.com/calabli/glide/releases/latest)

一个安静的浏览器扩展。网页右下角一枚小小的毛玻璃胶囊：**回到顶部 · 明暗切换 · 阅读模式 · 到底部**。平时完全看不见，滚动或把鼠标移过去时才淡入。

只申请「存储」一个权限，用来记住设置。不联网，不收集任何数据。

> 界面支持简体中文和英文，跟随浏览器语言自动切换。

## 悬浮按钮
- 位置可选：右下（默认）、左下、右侧中间、左侧中间（在设置面板里改）
- 平时完全隐藏；滚动时或鼠标靠近时淡入，停下约 1.4 秒后淡出
- 已在顶部时隐藏 ↑，已在底部时隐藏 ↓
- 支持在内部滚动的网页应用；阅读模式打开时，滚动的是阅读页
- 全屏看视频和打印时自动隐藏

## 夜间模式
- 切换时从按钮处圆形展开
- 底色是柔和的深灰（默认 #22242a），图片和视频保持原色
- **自动开启**（三选一）：
  - 跟随系统：macOS 或 Windows 切到深色时，没手动设置过的网站自动开启
  - 定时：例如 19:00–07:00，可跨午夜；到点自动切换，电脑睡眠醒来也会立刻检查
  - 关闭：只在你手动打开的网站使用
- **自动跳过深色网站**：网页本身已经是深色的，不会再被反色
- 手动切换后会记住这个网站；切回和自动规则一致的状态时，自动恢复跟随

> Windows：设置 → 个性化 → 颜色 → 选择默认应用模式「深色」。
> Chrome 的「设置 → 外观 → 模式」需要保持「设备」（跟随系统）。

## 设置面板（点工具栏上的 Glide 图标）
- 本网站夜间模式开关，可一键「恢复跟随系统」
- 本网站不自动开启：反色效果不理想的网站，自动开启时跳过（仍可手动开启）
- 本网站夜间亮度：60%–140%，只影响这个网站；点数值可重置
- 自动开启：跟随系统 / 定时（设置开始、结束时间）/ 关闭
- 夜间底色：石墨（默认）、夜蓝、暖棕、墨绿、纯黑；文字亮度滑块，带实时预览
- 按钮位置：右下、左下、右侧中间、左侧中间

## 阅读模式
- 自动找出正文，去掉导航、侧栏、评论、分享、广告
- 舒适的字号和行宽，顶部有阅读进度条，显示预计阅读时间
- 点胶囊上的书本按钮进入，打开时按钮高亮；再点一次、按 Esc 或右上角 × 退出
- **排版（右上角 Aa）**：字号、行宽（窄 / 中 / 宽）、字体（黑体 / 宋体）、朗读语速，全局记住
- **朗读（右上角 ▶）**：用系统自带语音逐段朗读，当前段落高亮并自动滚动；
  从屏幕上看到的第一段开始读，朗读中点任意段落可跳过去；
  优先使用本机语音（macOS「婷婷」、Windows「晓晓 / 慧慧」），不用联网

## 安装（Chrome / Edge / Arc）
1. 下载代码：在 [Releases](https://github.com/calabli/glide/releases/latest) 下载 `glide-x.y.z.zip` 并解压，或者 `git clone https://github.com/calabli/glide.git`
2. 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择 `glide` 文件夹

更新代码后，在扩展页点 Glide 卡片上的刷新 ↻，再刷新网页。

## 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 回到顶部 | ⌥⇧↑ | Alt+Shift+↑ |
| 到底部 | ⌥⇧↓ | Alt+Shift+↓ |
| 切换明暗 | ⌥⇧L | Alt+Shift+L |
| 阅读模式 | ⌥⇧R | Alt+Shift+R |

快捷键可以在 `chrome://extensions/shortcuts` 里修改。
