Glide 是一个安静的浏览器扩展。网页右下角一枚小小的毛玻璃胶囊：回到顶部、明暗切换、阅读模式、到底部。平时完全看不见，滚动或把鼠标移过去时才淡入。

Glide is a quiet browser extension. A small frosted-glass pill in the corner of every page: back to top, light / dark, reading mode, to bottom. It stays invisible until you scroll or move the mouse toward it.

四个按钮，
各管一件事。

Four buttons,
one job each.

胶囊停下 1.4 秒后自己淡出。已经在顶部时，↑ 会收起来；到了底部，↓ 也一样。全屏看视频、打印网页时，它会自动让开。

The pill fades out 1.4 seconds after you stop. At the top of a page, ↑ tucks itself away; at the bottom, so does ↓. It steps aside for fullscreen video and printing.

回到顶部

Back to top

平滑滚回开头，在页面空白处双击也行。邮箱、文档这类在内部滚动的网页也认得。

Glides back to the start, or double-click any blank space. Works in web apps like mail and docs that scroll inside a panel.

工具应当像空气一样

Tools should be like air

约 2 分钟读完2 min read

一个好的工具，应当像空气一样存在：需要时触手可及，不需要时毫无存在感。

A good tool should be like air: within reach when you need it, unnoticed when you don't.

很多扩展喜欢在页面上堆满按钮，生怕你找不到功能。真正好用的工具，只在你需要的那一刻出现，然后安静地退场。

Many extensions pile buttons onto the page in case you miss a feature. The good ones show up only at the moment you need them, then quietly leave.

动效也要克制。过渡控制在三百到五百毫秒之间，用缓出曲线，让元素像是被轻轻放下，而不是被扔到屏幕上。

Motion should be restrained too. Keep transitions between 300 and 500 milliseconds with an ease-out curve, so things are set down gently instead of thrown onto the screen.

看不见的细节。

Details you won't notice.

大部分时候你感觉不到它们，这正是目的。

Most of the time you won't feel them at all. That's the point.

每个网站分别记住

Remembers each site

在哪个网站开了夜间、调过亮度，下次打开还是那样。

Dark mode and brightness you set on a site are still there next time.

认得内部滚动

Knows inner scrolling

邮箱、文档这类网页应用在内部区域滚动，按钮照样好用。

Mail and docs apps that scroll inside a panel work just as well.

全屏和打印时让开

Out of the way

看视频进入全屏、打印网页时，胶囊自动隐藏。

The pill hides in fullscreen video and when you print a page.

四个位置可选

Four positions

右下、左下、右侧中间、左侧中间，避开网站自己的按钮。

Bottom right, bottom left, or the middle of either edge, clear of a site's own buttons.

尊重系统设置

Respects your system

系统开了「减弱动态效果」，所有动画都会关掉。

With “Reduce motion” on, every animation turns off.

不碰你的数据

Leaves your data alone

只申请「存储」一个权限，用来记住设置。不联网，不收集任何东西。

One permission, storage, to remember settings. No network requests, nothing collected.

一分钟装好。

Installed in a minute.

适用于 Chrome、Edge、Arc 等基于 Chromium 的浏览器。界面跟随浏览器语言，支持中文和英文。

For Chrome, Edge, Arc and other Chromium browsers. The interface follows your browser language, in English or Chinese.

  1. 下载代码Get the code

    从 GitHub 克隆，或在仓库页面点 Code → Download ZIP 并解压。

    Clone it from GitHub, or click Code → Download ZIP on the repository page and unzip.

    git clone https://github.com/calabli/glide.git

  2. 打开扩展管理页Open the extensions page

    在地址栏输入下面的地址并回车。Edge 用户把 chrome 换成 edge。

    Type this into the address bar and press Enter. In Edge, use edge:// instead.

    chrome://extensions

  3. 打开「开发者模式」Turn on Developer mode

    开关在页面右上角。

    The switch is in the top-right corner.

  4. 加载 glide 文件夹Load the glide folder

    点「加载已解压的扩展程序」，选择 glide 文件夹。网页右下角出现胶囊，就装好了。

    Click Load unpacked and choose the glide folder. When the pill appears in a page's corner, you're set.
